# 佐賀・小さな旅

佐賀県の自然や風景、グルメ、温泉などの魅力を紹介する、観光Webサイトです。

日帰りや短い休日でも楽しめる「小さな旅」をテーマに、佐賀を訪れるきっかけになるようなサイトを目指して制作しています。

## 制作目的

HTML・CSSを中心としたWebサイト制作の学習成果として、オリジナルのポートフォリオサイトを制作しています。

企画・構成・デザイン・コーディング・画像素材の選定など、Webサイト制作に必要な工程を実際に経験することを目的としています。

## サイト構成

| ページ | ファイル名 | 主な内容 |
|---|---|---|
| TOPページ | index.html | 各ページの入口となるタイル型メニュー |
| モデルコース | course.html | 1泊2日で巡る佐賀の旅行プラン |
| 佐賀の見どころ | spots.html | 自然・歴史・文化などの観光スポット |
| グルメ | gourmet.html | 佐賀牛やご当地グルメの紹介 |
| 温泉 | onsen.html | 嬉野温泉や武雄温泉などの紹介 |
| About | about.html | サイトのコンセプトや制作者について |

## デザイン

佐賀県の観光サイトをイメージし、写真を活かしたタイル型のレイアウトを採用しています。

観光地やグルメの写真を複数配置することで、ユーザーが興味のある場所を見つけやすく、楽しみながらサイトを閲覧できるデザインを目指しています。

## Photoshopで制作したもの

- PC用・スマートフォン用のトップページ背景画像
- 「佐賀・小さな旅」のタイトルロゴ
- モデルコース・見どころ・グルメ・温泉・Aboutのオリジナルアイコン
- 見出しの飾りとカード用装飾
- ブラウザーのタブに表示するファビコン
- イマリンビーチ・呼子のイカ・嬉野温泉「シーボルトの湯」の写真補正
- PC表示とスマートフォン表示をまとめたポートフォリオ紹介画像
- SNSでの共有を想定したOGP画像
- 伊万里ビーチと複数のバルーンを組み合わせた合成画像
- 写真に半透明の色を重ね、文字を読みやすくした画像
- 葉のモチーフを繰り返し配置した背景パターン

制作データは編集可能なPSD形式で保存し、Webなどで使用できるJPG・PNG形式でも書き出しています。

## 素材について

Webサイトで使用している写真・素材については、各素材サイトの利用規約・ライセンスを確認したうえで使用しています。

使用素材については、以下の点を確認しています。

- Webサイトのポートフォリオで利用可能
- 商用利用可能
- ライセンスが明確
- 素材サイトの公式ライセンスを確認
- 使用した素材を記録
